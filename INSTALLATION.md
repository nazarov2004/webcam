# Installation Guide

## Windows Desktop (LensCast Desktop)
1. Build or download the Windows release folder (`build/windows/x64/runner/Release/`).
2. Run `lenscast.exe`.
3. When prompted by Windows Defender Firewall, allow access on **Private networks**.

## Android Mobile (LensCast Mobile)
1. Build or download `app-release.apk` (`build/app/outputs/flutter-apk/app-release.apk`).
2. Install on your Android device (Android 8.0 / API 26+ recommended).
3. Grant **Camera**, **Microphone**, and **Notification** permissions on first launch.

## First Connection
1. Open **LensCast Desktop** → **Devices & QR** to view your QR code and 6-digit PIN.
2. Open **LensCast Mobile** → **Connection** → **Scan QR Code**.
3. Your phone camera preview will appear in LensCast Desktop within seconds.
4. Follow [OBS_SETUP.md](OBS_SETUP.md) to add LensCast to OBS Studio.
